# sergchil/homebrew-tap

Homebrew casks by sergchil.

## BrowserBro

Opens every link in the right browser and profile. https://github.com/sergchil/browserbro

```bash
brew install --cask sergchil/tap/browserbro
```

Update: `brew upgrade --cask browserbro`

BrowserBro is ad-hoc signed and not notarized. The cask removes the quarantine flag after install, so macOS does not block the first launch.
